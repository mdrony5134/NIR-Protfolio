## 🚀 Next.js App Router Multi-Page Architecture

```
src/
├── app/
│   ├── layout.jsx            # RootLayout with theme system, meta tags, Navbar, Footer
│   ├── page.jsx              # Landing Home Page (Modular overview)
│   ├── about/
│   │   └── page.jsx          # Dedicated About Me & Education Page
│   ├── experience/
│   │   └── page.jsx          # Dedicated Career Timeline & Company Details
│   ├── projects/
│   │   └── page.jsx          # Full Interactive Projects Showcase (Search + Filter)
│   ├── skills/
│   │   └── page.jsx          # Technical Skills Matrix & Engineering Standards
│   └── contact/
│       └── page.jsx          # Direct Contact & Formspree Form Integration
├── components/
│   ├── layout/               # Header (Navbar), Footer, ScrollToTop
│   ├── modules/              # Hero, Experience, Projects, Skills, Education, Contact
│   └── ui/                   # SectionHeader, Divider, LottieAnimation, DynamicIcon
├── data/
│   ├── personalInfo.js       # Bio, roles, contact info, social links, stats
│   ├── experienceData.js     # Easy Fashion Ltd, SM Technology, Radisson Digital
│   ├── projectsData.js       # Production client projects & open source apps
│   ├── skillsData.js         # Categorized skills matrix with proficiency levels
│   └── educationData.js      # Degrees, CGPA, institutional awards & honors
└── styles/
    ├── globals.css           # Luxury dark & clean light mode tokens, animations
    └── icons.css             # Absolute font-path icomoon icons
```

- **Animations**: Framer Motion, Lottie React, React Type Animation
- **Icons**: React Icons (FontAwesome, SimpleIcons) & Icomoon
- **Forms & Integration**: Formspree React, Clipboard API
